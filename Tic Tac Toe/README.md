# Tic Tac Toe

A simple browser-based Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- Multiplayer mode for two human players
- Computer mode with a basic random move AI
- Player name input before starting the game
- Restart and retry controls for quick game resets
- Responsive layout using Bootstrap

## Files

- `index.html` - main page structure and game UI
- `style.css` - custom styles and board layout
- `script.js` - game logic, player interaction, and win detection

## How to Run

1. Open `index.html` in a web browser.
2. Choose either `Multiplayer` or `Computer` mode.
3. Enter player names and click `Start`.
4. Click on board cells to place `X` or `O`.

## Notes

- The computer player chooses empty cells randomly.
- `Retry` clears the board and keeps the current players.
- `Restart` reloads the page to reset the game state.
